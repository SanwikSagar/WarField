## Foliage rendering reference
NVIDIA GPU Gems, Chapter 7, "Rendering Countless Blades of Waving Grass" by Kurt Pelzer: multi-directional grass clumps, distance transitions and per-object wind variation. Implementation is original; no sample code or images were copied.
